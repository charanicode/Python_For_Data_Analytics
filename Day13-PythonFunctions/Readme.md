# Day 13 – Python Functions 🧩

## Overview
Learned Python functions and different methods of passing arguments, along with lambda functions and recursion.

## Topics Covered
- Defining and calling functions
- Default arguments
- Positional arguments
- Keyword arguments
- Variable-length arguments using `*args`
- Iterating through values received by `*args`
- Finding the number and type of arguments
- Creating lambda functions
- Squaring numbers using lambda
- Adding two numbers using lambda
- Calculating factorial using recursion
- Printing numbers from 1 to 5 using recursion

## Concepts Practised
- `def` keyword
- Function parameters and arguments
- Default arguments
- Positional and keyword arguments
- `*args`
- Lambda expressions
- Recursion
- Base condition and recursive calls
- Return statements

## Learning Outcome
Developed an understanding of reusable functions, argument handling, lambda expressions, and recursive problem-solving.
