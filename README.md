## 📅 Day 6 – Logical Operators and Introduction to Bits

### 1. Logical Operators

Logical operators combine multiple conditions and return Boolean results (`True` or `False`).

| Operator | Description |
|---|---|
| `and` | Returns True when both conditions are True. |
| `or` | Returns True when at least one condition is True. |
| `not` | Reverses the Boolean result. |

**AND Operator**
- Returns True only when all conditions are True.
- If any condition is False, the result is False.

**OR Operator**
- Returns True if at least one condition is True.
- Returns False only when all conditions are False.

### 2. Introduction to Bits

A bit is the smallest unit of data in computing.

- `0` – OFF
- `1` – ON

Computers represent data using binary numbers consisting of 0s and 1s.

### Understanding Binary Numbers

| Decimal | Binary |
|---|---|
| 1 | 0001 |
| 2 | 0010 |
| 3 | 0011 |
| 4 | 0100 |
| 5 | 0101 |
| 6 | 0110 |
| 7 | 0111 |
| 8 | 1000 |

### Key Learnings
- Understood logical operators.
- Practiced AND and OR operators using multiple conditions.
- Applied logical operators to an employee eligibility example.
- Learned the fundamentals of bits and binary representation.

## 📅 Day 7 – Python Operators

### 1. Bitwise Operators

Bitwise operators perform operations on binary representations of integers.

| Operator | Description |
|---|---|
| `&` | Bitwise AND |
| `\|` | Bitwise OR |
| `^` | Bitwise XOR |
| `~` | Bitwise NOT |
| `<<` | Left Shift |
| `>>` | Right Shift |

### 2. Membership Operators

Check whether an element exists in a sequence.

- `in` – Returns True if an element exists.
- `not in` – Returns True if an element does not exist.

### 3. Identity Operators

Check whether two variables refer to the same object.

- `is` – Returns True if both variables refer to the same object.
- `is not` – Returns True if they refer to different objects.

### Concepts Practiced
- Bitwise operations using integers.
- Checking character availability in strings.
- Understanding object identity.
- Practicing Python operator syntax.

**Learning Outcome:** Gained practical understanding of bitwise, membership, and identity operators.
