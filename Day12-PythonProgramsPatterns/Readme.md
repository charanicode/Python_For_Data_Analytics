# Day 12 – Python Programs and Patterns 🔢

## Overview
Practised Python programming problems using nested loops, number patterns, star patterns, and basic functions.

## Topics Covered
- Finding prime numbers between 2 and 100
- Printing right-angled star patterns
- Printing number patterns
- Printing repeated row numbers
- Printing increasing number sequences
- Printing continuous number triangles
- Printing right-aligned star and number patterns
- Printing hourglass-style star patterns
- Printing square star patterns
- Printing hollow square patterns
- Creating and calling simple functions
- Adding and subtracting numbers using functions

## Concepts Practised
- Nested for loops
- Conditional statements
- Loop counters
- `range()` function
- `print()` with `end`
- Functions, parameters, and return statements

## Learning Outcome
Strengthened logical thinking and problem-solving skills through nested loops and pattern-based programming exercises.
