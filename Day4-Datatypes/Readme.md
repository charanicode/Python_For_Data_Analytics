# 🐍 Python Learning Journey – Day 4

## 📚 Topic: Python Data Types

On Day 3, I explored the fundamental data types in Python and practiced working with different types of variables and collection data structures using Jupyter Notebook.

### 📌 Topics Covered

**1. Basic Data Types**

- Integer (`int`) – Stores whole numbers.
- Float (`float`) – Stores decimal numbers.
- String (`str`) – Stores text values.
- Boolean (`bool`) – Represents `True` or `False`.
- Used the `type()` function to identify the data type of variables.
- Practiced assigning different values to variables.

**2. Collection Data Types**

- **List:** Stores multiple elements in an ordered collection.
- **Tuple:** Stores multiple elements in an ordered collection.
- **Set:** Stores unique elements.
- **Dictionary:** Stores data in key-value pairs.

### 💻 Practical Implementation

- Created variables with different data types.
- Checked variable types using `type()`.
- Created and displayed lists, tuples, sets, and dictionaries.
