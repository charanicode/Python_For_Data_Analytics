# Day 11 – Python For Loops 🐍

## Overview
Practised Python `for` loops and the `range()` function through basic programming exercises.

## Topics Covered
- Printing multiplication tables
- Printing odd numbers in a range
- Printing even numbers using `range()`
- Checking even and odd numbers using the modulo operator
- Printing numbers from 0 to 10
- Printing numbers in reverse order
- Calculating factorial using a for loop
- Checking whether a number is prime

## Concepts Practised
- For loops
- `range()` function
- If-else conditions
- Modulo operator (`%`)
- Loop counters and variables

## Learning Outcome
Improved understanding of loops and developed logical thinking by solving basic mathematical problems using Python.
