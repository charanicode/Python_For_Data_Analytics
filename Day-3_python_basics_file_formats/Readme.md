### 2. Exploring Python File Formats in VS Code

Explored two commonly used Python file formats:

**`.py` – Python Script**
- Stores Python code in a standard script file.
- Used to write and execute complete Python programs.
- Suitable for application development and automation.

**`.ipynb` – Jupyter Notebook**
- Allows writing and executing Python code in individual cells.
- Supports combining code, Markdown text, and outputs.
- Useful for data analysis, experimentation, and visualization.
