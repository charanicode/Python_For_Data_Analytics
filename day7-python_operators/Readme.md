# Day 7 – Python Operators

## 📌 Topics Covered

This file contains practice examples of the following Python operators:

### 1. Bitwise Operators
Bitwise operators perform operations on binary representations of integers.

| Operator | Description |
|---|---|
| `&` | Bitwise AND |
| `|` | Bitwise OR |
| `^` | Bitwise XOR |
| `~` | Bitwise NOT |
| `<<` | Left Shift |
| `>>` | Right Shift |

### 2. Membership Operators

Membership operators check whether an element exists in a sequence.

- `in` – Returns True if an element exists.
- `not in` – Returns True if an element does not exist.

### 3. Identity Operators

Identity operators check whether two variables refer to the same object.

- `is` – Returns True if both variables refer to the same object.
- `is not` – Returns True if they refer to different objects.
