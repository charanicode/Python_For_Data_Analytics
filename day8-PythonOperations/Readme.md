# Day 8 – Python Operations

## 📌 Topics Covered

This file focuses on different methods of swapping two variables and basic conditional statements.

### 1. Swapping Variables Using a Temporary Variable

Using a third variable to exchange the values of two variables.

### 2. Swapping Without a Temporary Variable

Using Python's multiple assignment feature:

```python
a, b = b, a
```

### 3. Swapping Using Addition and Subtraction

Exchanging values using arithmetic operations.

### 4. Swapping Using Multiplication and Division

Using multiplication and floor division to swap values.

### 5. Swapping Using XOR

Using the XOR (`^`) bitwise operator to exchange two integer values.

### 6. Conditional Statements

Practiced `if-else` statements using:

- Voting eligibility based on age.
- Exam eligibility based on fee payment and attendance.

## 💻 Concepts Practiced

- Variable assignment.
- Temporary variables.
- Multiple assignment.
- Arithmetic operators.
- Bitwise XOR.
- Conditional statements.
- Logical AND operator.
